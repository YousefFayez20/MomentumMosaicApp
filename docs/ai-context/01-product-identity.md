# Product Identity

Momentum Mosaic is a Daily Discipline System.

It is not a generic task manager, passive analytics dashboard, habit toy, life operating system, second brain, or productivity content platform. It exists to help a person decide what matters today, enter focused execution, and build momentum through consistent follow-through.

## Product Positioning

Momentum Mosaic sits between a to-do list, a focus timer, and a personal progress signal. Its value is not simply recording what happened. Its value is helping the user move through the loop:

```text
Plan -> Commit -> Execute -> Complete -> Reflect
```

The product should feel like a serious training partner: calm, direct, structured, and quietly encouraging.

## Core Philosophy

- Today over lifetime stats. The primary surface should answer: "What does today require?"
- Execution over curation. The system should help the user act, not organize endlessly.
- One active commitment. A focus session should make the current task feel protected.
- Momentum through consistency. Progress is built from repeated daily signals, not spectacle.
- Dignified feedback. Acknowledgement should be precise and earned, not loud or patronizing.
- Simplicity as discipline. If a feature creates maintenance burden, it must prove its value.

## Emotional Direction

The product should feel:

- grounded
- calm
- focused
- purposeful
- premium but restrained
- serious without being cold
- supportive without cheerleading

It should not feel:

- noisy
- gamified
- childish
- corporate
- bureaucratic
- overloaded
- like a dashboard clone
- like a second brain

## Behavioral Goals

Momentum Mosaic should help the user:

- see the day clearly
- choose the next commitment
- start a focus session intentionally
- protect attention during execution
- complete work with closure
- notice momentum building over time
- recover without shame after missed days

## Anti-Goals

Do not optimize for:

- unlimited task capture
- nested project management
- knowledge graph building
- complex note databases
- social comparison
- leaderboards
- excessive gamification
- enterprise workflow management
- analytics that do not guide action
- persistent clutter disguised as productivity

## Product Voice

The voice should sound like a serious coach, not a cheerful app.

Use:

- short, concrete acknowledgements
- present-tense guidance
- calm language
- direct labels
- meaningful completion feedback

Avoid:

- "Amazing!"
- "You are a superstar!"
- shame for missed work
- forced motivation
- empty productivity slogans
- generic success copy

## Strategic Boundary

Every feature must answer at least one of these questions:

- What should I do today?
- What am I committing to now?
- How do I stay inside this execution block?
- What did I complete?
- What is my momentum telling me?

If a feature does not strengthen one of these questions, it probably does not belong in the core product.
